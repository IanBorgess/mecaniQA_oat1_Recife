## Commands Reference

### Docker Compose
```powershell
docker compose up --pull always       # Start all services
docker compose down                    # Stop all services
docker compose logs java-api           # View logs
docker ps                              # List running containers
```

### Terraform
```powershell
cd terraform/
terraform init                         # Initialize
terraform plan                         # Preview changes
terraform apply                        # Deploy infrastructure
terraform destroy                      # Tear down
```

### Kubernetes
```powershell
# Minikube
C:\minikube.exe start --driver=docker # Start cluster
C:\minikube.exe image load my-corretto-app:optimized  # Load image

# kubectl
kubectl apply -f k8s/                  # Deploy all manifests
kubectl get pods -n app-system         # List pods
kubectl logs -n app-system <pod-name>  # View logs
kubectl describe pod -n app-system <pod-name>  # Describe pod
kubectl port-forward -n app-system svc/java-api 8080:8080  # Port forward API

# K9s (monitoring)
k9s                                    # Launch dashboard
```

## Known Issues & Solutions

1. **Kubernetes image pull failure**
   - Solution: `minikube image load my-corretto-app:optimized`

2. **Docker Desktop Kubernetes not starting**
   - Solution: Use Minikube instead with Docker driver

3. **Gradle xargs error in Dockerfile**
   - Solution: Install findutils in builder stage

4. **Terraform Windows Docker socket**
   - Solution: Use `npipe:////.//pipe//docker_engine` instead of Unix socket
